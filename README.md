# 교대달력

광고 없는 4조 2교대(주주휴휴야야휴휴) 근무 달력 PWA. 같은 공장·같은 반 동료끼리 휴가·대근을 실시간으로 공유합니다.

- 프론트엔드: HTML + JavaScript (빌드 과정 없음, GitHub Pages에 그대로 올리면 됨)
- 서버: Supabase 프로젝트 `shift-calendar` (서울 리전, 무료 플랜) — DB 구조는 이미 적용돼 있음

## 1. 처음 한 번: Supabase 설정 (필수)

Supabase 대시보드 → `shift-calendar` 프로젝트 → **Authentication** → 이메일 로그인 설정에서 **Confirm email** 을 끕니다.

- 켜 두면 가입할 때마다 인증 메일이 나가는데, 기본 메일 서버는 시간당 발송 수가 매우 적고 메일 속 링크도 `localhost`로 연결돼 동료들이 가입을 못 합니다.
- 메뉴 이름·위치는 Supabase 업데이트로 바뀔 수 있습니다.

## 2. 내 PC에서 실행해 보기

```bash
cd shift-calendar
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

> `index.html`을 더블클릭(file://)하면 모듈 로딩이 막혀서 동작하지 않습니다. 꼭 위처럼 서버로 여세요.

## 3. GitHub Pages 배포

```bash
cd shift-calendar
git init
git add .
git commit -m "교대달력 첫 버전"
gh repo create shift-calendar --public --source=. --push
```

그다음 GitHub 저장소 → **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
1~2분 뒤 `https://<깃허브아이디>.github.io/shift-calendar/` 로 접속됩니다.

- `js/config.js`의 키는 **publishable 키**라 공개 저장소에 있어도 됩니다. 데이터는 DB의 RLS(행 단위 보안)로 같은 팀원에게만 보입니다.
- 절대 `service_role` 키나 `secret` 키는 넣지 마세요.

## 4. 사용 순서

1. **통합 운영자**(앱 만든 사람): 내 정보 → **운영자 메뉴**에서 반(팀)을 만들고, 반마다 **관리자 초대 코드(1회용)**를 발급해 주임에게 보냅니다.
   - 관리자 초대 코드로 가입하면 승인 없이 바로 그 반의 관리자가 되고, 코드는 사라집니다. 필요하면 운영자 메뉴에서 재발급.
   - 운영자는 다른 반에 들어가지 않고, 팀 관리자가 운영자를 내보내거나 권한을 내릴 수 없습니다.
   - 일반 사용자 화면에는 '새 팀 만들기'가 없습니다.
2. 각 반 관리자: **내 정보** 탭 → 일반 초대 코드 **공유** → 같은 반 동료에게 전달
3. 동료: **초대 코드로 가입** → ① 초대 코드 확인 → ② 직번·이름·비밀번호 입력 → ③ **관리자 승인 대기** → ④ 승인 후 **내 조** 선택
   - 관리자는 **내 정보** 탭의 "가입 승인 대기"에서 승인/거절합니다 (새 신청이 오면 알림·배지 표시).
4. 이후 로그인은 **직번 + 비밀번호** — 로그인 상태는 유지되고, 로그아웃해도 마지막 직번은 미리 채워집니다.

**인사이동**: 내 정보 → **조 변경** → 새 조 + "언제부터" 입력. 그 이전 근무·통계는 그대로 남고, 그 날 이후의 휴가·대근만 새 근무표에 맞게 자동 정리됩니다. 관리자는 팀원 이름을 눌러 대신 바꿀 수도 있어요.

근무 기준은 회사 공통으로 고정돼 있습니다: **2026-11-23 = C조 주간 1일차** (`js/config.js`의 `COMPANY_ANCHOR`). 팀을 만들 때 따로 고를 필요가 없어요.
5. 홈 화면에 추가: Android Chrome은 "앱 설치", iPhone은 Safari **공유 → 홈 화면에 추가**

## 5. 동작 규칙

| 상황 | 결과 |
|---|---|
| 내 달력에서 근무 변경 | 팀 달력에 바로 반영 (공개/비공개 선택 없음) |
| 근무일을 **휴가·교육·검진·출장·예비군**으로 변경 | 팀 달력에 "대근 필요" 자동 등록 |
| **내 근무 타입**(커스텀, 예: 압대) 선택 | 내 달력엔 그 이름·색, 팀 달력엔 고른 **기준 근무**로 표시 |
| 휴무인 사람이 **대근 지원** | 지원자 목록에 추가 (그날 근무 있으면 지원 불가) |
| 휴가 등록자 또는 관리자가 **확정** | 대근자 개인 달력에 "대근" 자동 기입 |
| 휴가 취소 | 대근 요청 취소 + 확정된 대근자 근무도 원래대로 |
| 대근자가 그날 근무를 바꿈 | 대근 확정 해제 → 다시 "대근 필요" |
| 휴가 종류·메모 | 본인만 보임 (팀에는 "휴가"만 표시) |
| 조 변경 (12/1부터) | 11/30까지는 이전 조, 12/1부터 새 조로 계산 · 새 조로 근무일이 된 날의 대근은 해제 |

- 팀을 만든 사람이 관리자. **내 정보 → 팀원 이름**을 눌러 **관리자 넘기기**(나는 일반 팀원이 됨) 또는 **관리자 추가 지정**(주임 여러 명)을 할 수 있습니다.
- 근무 기준일은 07:00. 새벽 6시에 열면 "오늘"은 전날(야간 근무 중)로 표시됩니다.

### 근무 타입
- **고정 8종** (변경 불가, 팀 달력·대근 계산 기준): 주간 · 야간 · 휴무 · 휴가 · 교육 · 검진 · 출장 · 예비군
- **내 근무 타입** (내 정보 → 내 근무 타입 관리, 또는 날짜 시트의 "편집"): 이름(최대 6자)·색·기준 근무를 정해서 만듭니다. 본인 화면에만 보입니다.
- 기준 근무 **자동**(대근용 추천): 근무일이면 그 근무, 쉬는 날이면 앞뒤로 붙은 본근무로 정해집니다. 휴무 1일차=주간, 2일차=야간, 3일차=야간, 4일차=주간. 예외는 날짜 시트에서 "주간/야간으로 바꾸기"로 직접 고릅니다.
- 팀 달력 색은 팀 공통 테마(주 노랑 · 야 검정 · 휴 빨간 글씨 · 휴가 파랑 · 교육 청록 · 검진 초록 · 출장 보라 · 예비군 베이지 · 대근 주황)로 고정입니다.

## 6. 파일 구조

```
index.html            화면 틀
css/style.css         디자인
js/shift.js           근무 계산(패턴·통계) — 화면과 분리돼 있어 나중에 Dart로 옮기기 쉬움
js/app.js             화면·Supabase 연동·실시간
js/config.js          Supabase 주소·키, 직번 로그인 도메인, 회사 근무 기준일, 기본 공장명
vendor/supabase.js    supabase-js 2.119.2 (CDN 대신 내장 — 오프라인에서도 화면 로딩)
sw.js                 서비스 워커(오프라인 캐시)
manifest.webmanifest  PWA 설치 정보
supabase/schema.sql   DB 구조 사본 (프로젝트에는 이미 적용됨, 재구축용)
```
